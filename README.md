## 🧠 What I'm Building

### Pi × TencentDB Agent Memory

A native Pi adapter for **durable cross-session memory and reusable skill learning**.

* L0–L3 bounded memory recall
* Durable capture & offline recovery
* Cross-process lease and retry
* Skill learning → Pi native Skills
* Branch isolation & fail-open design
* Unit tests + real Pi / MemoryCore E2E verification

**Open-source PR:** TencentCloud/TencentDB-Agent-Memory#1070

### 🤖 AgentDrivenCompetBench

A multi-agent competitive intelligence system built around a real **QA feedback loop** instead of a linear Agent pipeline.

`LangGraph` · `FastAPI` · `Vue 3` · `Pydantic` · `SSE` · `Langfuse`

```text
Discovery → Collector → Analyst → Writer → QA
                                      ↓
                          Pass / Revise / HITL
```

Focus:

* Multi-Agent orchestration
* QA-driven iterative revision
* Evidence traceability
* Human-in-the-loop
* LLM observability
